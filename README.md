## 🎯 Purpose

- To document and organize daily learning sessions with Node.js
- To practice backend concepts such as:
  - File system operations
  - Routing and middleware
  - Express.js basics
  - Basic REST API development
- To build and experiment with small projects (e.g., Restaurant app)

## 🧰 Technologies Used

- Node.js
- Express.js (in some folders)
- HTML & CSS (in the `html/` folder)
- File system modules and native Node features

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/aadil-ansari-rd/your-repo-name.git
   cd your-repo-name
   ````

2. Navigate to any folder (e.g.):

   ```bash
   cd node-240911
   ```

3. Run the Node.js file:

   ```bash
   node index.js
   ```

   > Or the corresponding file based on folder contents.
